Detected Bottlenecks

Socket.IO Session Expiry (25s pingInterval)

Socket.IO sessions expire in 25 seconds if no ping is sent. Script now sends ping packet "2" every 10 seconds during bid loop to prevent "Session ID unknown" errors.

Bidder Reserved Status Blocks Assignment

Server marks bidders as reserved when assigned to auctions. Setup closes all existing auctions first (Step 2.5) to unreserve bidders before creating new test auctions.

PostgreSQL Connection Pool Pressure

Each bid triggers a DB write (coin deduction + bid record). Knex default pool of 10 will queue under concurrent load. Watch for timeout errors at peak.

Auction Timer Broadcast

Server emits auction:timer every second to all room members. Monitor event loop lag during peak with multiple active auctions.

Recommendations
1

Increase PostgreSQL pool — pool.max=100 + PgBouncer

Set Knex pool.max=100 and add PgBouncer to handle concurrent bid writes.

2

Run PM2 in cluster mode with Redis adapter

pm2 start app.js -i max. Add @socket.io/redis-adapter for cross-instance room support.

3

Cache GET /api/auction/auctions with Redis 5s TTL

Every VU calls this endpoint — a short cache reduces DB reads by 95% at peak.

4

Throttle auction:timer to every 3s for large rooms

Reduces event loop broadcast pressure by 66% for rooms with 100+ concurrent bidders.

5

Add direct bidder unreserve API endpoint

Currently bidders can only be unreserved by closing an auction. A direct unreserve endpoint would simplify test setup and auction management.
